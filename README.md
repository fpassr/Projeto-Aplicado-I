## Sobre o projeto

Este repositório contém o desenvolvimento do Projeto Aplicado I, cujo objetivo é
realizar um estudo prático de análise de dados sobre uma organização real,
culminando em um data storytelling ao final do semestre.

## Organização escolhida

**Olist** — plataforma de marketplace de e-commerce brasileira, que conecta
pequenos e médios vendedores a múltiplos canais de venda.

## Estrutura do repositório

- `dados/` — dataset utilizado no estudo (Brazilian E-Commerce Public Dataset by Olist)
- `entregas/` — PDFs entregues a cada etapa do projeto
